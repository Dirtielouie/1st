## One-Pager Décision Achat

`one-pager/index.html` : outil qui génère une note de décision A4 pour un comité de direction
(achat d'un logiciel métier) à partir des notes de réunion.

1. Collez les notes d'une réunion (date + titre facultatif) et cliquez sur **Mettre à jour le one-pager**.
2. Claude fusionne les nouvelles informations dans les 6 sections : Contexte, Pourquoi maintenant ?,
   Investissement, ROI, Conformité, Prochaines étapes (+ décision demandée, recommandation, points ouverts).
3. Corrigez n'importe quel texte directement sur la feuille ; vos corrections sont conservées aux mises à jour suivantes.
4. Exportez en PDF A4 ou copiez le texte pour un e-mail.

Plusieurs dossiers (un par logiciel évalué) et l'historique des réunions sont conservés.
« Tout régénérer » reconstruit le document à partir de toutes les notes.

Utilisation : publiée comme artefact claude.ai (stockage partagé + Claude intégré). Ouverte en local
dans un navigateur, la page demande une clé API Anthropic et stocke les données dans le navigateur.
